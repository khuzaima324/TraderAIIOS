# Traders AI – Mobile Application

Traders AI is a cross-platform mobile application built to provide AI-powered market analysis, chart breakdowns, trade setups, and social media tracking insights.

This repository contains the unified source code for both the iOS and Android applications, utilizing a shared React Native codebase managed via Expo.

---

## 🛠 Tech Stack Overview

* **Framework:** React Native / Expo (SDK 52+)
* **Languages:** TypeScript, JavaScript
* **Backend / Database:** Firebase (Authentication, Firestore)
* **In-App Purchases:** RevenueCat
* **AI Engine:** Google Generative AI (Gemini 2.0 Flash)
* **Social Data:** Twitter / X Advanced Search APIs
* **Styling:** React Native StyleSheet / Reanimated
* **Navigation:** Expo Router

---

## 🚀 Local Development Setup

To run this project locally on your machine, follow these steps:

### 1. Prerequisites
* **Node.js:** Version 18.x or 20.x recommended.
* **Package Manager:** npm (comes with Node.js).
* **Expo CLI:** Install globally via `npm install -g expo-cli`.
* **iOS:** Xcode (Mac only) and CocoaPods.
* **Android:** Android Studio and Android SDK.
